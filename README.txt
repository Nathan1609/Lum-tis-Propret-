Lumétis Propreté – prototype de site fictif (nettoyage de bureaux)

Structure :
  index.html      page unique (6 sections)
  css/style.css   styles (palette #14213D / #FCA311 / #FFFFFF / #E5E5E5, police Roboto)
  js/script.js    animations au scroll, menu actif, formulaire de démonstration

Utilisation : ouvrir index.html dans VS Code puis le lancer avec l'extension « Live Server »,
ou simplement double-cliquer dessus dans un navigateur.

Mise en ligne : envoyer le contenu du dossier à la racine de l'hébergement
(Netlify, GitHub Pages, hébergeur FTP, etc.).

Attention : la police Roboto est chargée depuis Google Fonts (connexion requise).
Le formulaire est un prototype : il n'envoie rien. Toutes les coordonnées sont fictives.
